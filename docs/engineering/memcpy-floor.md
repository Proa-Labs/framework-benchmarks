# Memcpy mechanism floor

[Figure 03](../figures/03-representative-matrix.svg) uses the current canonical rendering table and the latest matched copy controls. Each denominator copies the corresponding pre-rendered Proa payload into warmed, preallocated output. Rendering, allocation, hashing and network transfer are outside the copy timer.

This is an optimistic hot-buffer mechanism floor, not a renderer or an HTTP throughput result. Copy and rendering are separate captures, with their dates and output sizes disclosed. A copy control cannot appear as a technology row.
