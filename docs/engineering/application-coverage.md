# Application-shaped rendering coverage

The [linked showcase experiment](../../experiments/showcase/README.md) covers twelve pinned Proa pages and four interactive browser pages. Its latest SSR results are in [the engineering report](../reports/engineering.md#refreshed-linked-showcase-corpus).

These are standalone Proa experiments. They require equivalent peer implementations and shared correctness and timing contracts before becoming framework comparisons. Their SSR and browser measurements answer different questions and stay separate.
