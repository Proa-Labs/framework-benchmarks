# Runtime and framework-local experiments

The public React row uses the pinned production runtime and the same workload as its peers. Runtime comparisons require rerunning every runtime on the same machine and fixture; old Node/Bun/Deno measurements have been removed.

Streaming completion must also be defined consistently. See the [current resolved-HTML HTTP report](../reports/http-capacity.md) and the separate [native streaming/browser experiment](../reports/sveltekit.md).
