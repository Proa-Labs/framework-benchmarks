# Integer-to-ASCII scaling

This engineering fixture interpolates signed and unsigned integers in text and attributes through each engine's native formatter. Input construction stays outside timing. Independently owned output and prewarmed reusable output are different experiments.

The latest Proa-only controls are generated in [the engineering report](../reports/engineering.md#proa-engineering-refresh). Older cross-framework measurements have been removed; they must not be combined with the current framework scoreboard.

Run the fixture with `./benchmarks/rendering/run_all.sh integers`.
